# dissertate

creating a Quarto extension for dissertations \& theses, starting with Montclair State University (with plans to extend capability to other Universities)

# Design feature priorities

1. conformity to graduate school format (margins, fonts, etc)
2. advisor--friendly (note--taking and idea--sharing maximized)

   * html version for editing
   * pdf final for graduate school

# Execution

Quarto extension most likely enabled via/constructed with the help of [https://github.com/Jupyter4Science/awesome-quarto-thesis](https://github.com/Jupyter4Science/awesome-quarto-thesis)
